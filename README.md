# PS Таймер

Бесплатное веб-приложение для учёта игровых сеансов в PlayStation-клубе.

## Функции
- Русский интерфейс и суммы в UZS («сум»)
- 20 стартовых таймеров, количество можно увеличивать по необходимости (практический предел зависит от устройства и браузера)
- независимые таймеры, старт/стоп, переименование приставок
- пропорциональная поминутная оплата по цене часа; итог округляется до целого сума
- активная стоимость обновляется каждую секунду
- история сеансов, выручка за сегодня и общая выручка
- экспорт истории CSV, резервная копия JSON и восстановление
- PWA-манифест и service worker для установки/офлайн-загрузки

## Важное ограничение
Данные хранятся локально в браузере текущего устройства. Это приложение не синхронизирует данные между разными телефонами и не имеет серверной базы. Регулярно скачивайте резервную копию. Очистка данных сайта в Safari может удалить историю.

## Как запустить на компьютере для проверки
Откройте терминал в этой папке и выполните:
`python3 -m http.server 8000`
Затем откройте `http://localhost:8000`.

Для PWA установка и service worker требуют HTTPS (или localhost). Чтобы опубликовать бесплатно, загрузите эти файлы в новый публичный GitHub-репозиторий и включите Settings → Pages → Deploy from a branch → main / root. После публикации откройте выданный HTTPS URL в Safari на iPhone, нажмите «Поделиться» → «На экран Домой».

## Первое использование
1. Откройте «Тарифы» и укажите цену за час.
2. Укажите число приставок и сохраните.
3. Нажимайте «Старт» при посадке клиента, «Стоп и расчёт» при уходе.
4. Регулярно нажимайте «Скачать резервную копию».


## Обновлённые возможности
- Индивидуальные названия, тарифы и заметки для каждой приставки
- Быстрое копирование тарифа на выбранные приставки
- Защита тарифа активного сеанса при изменении настроек
- Запуск сеанса на заданное количество минут и уведомление по окончании, пока страница активна; фоновые уведомления зависят от возможностей iOS/Safari
- Статус обслуживания и бронирования с проверкой пересечения по одной приставке
- Бронирования и данные хранятся локально на устройстве; синхронизации между телефонами пока нет
